# COVID-19-Global-Data-Analysis-Using-Python

## Project Overview

The COVID-19 pandemic created an urgent need for data-driven decision-making in public health. This project analyzes global COVID-19 confirmed cases, deaths, and recoveries using Python to uncover trends, compare country-level outcomes, and evaluate recovery and mortality patterns over time
The analysis demonstrates practical data analyst skills, including data cleaning, transformation, visualization, and insight generation using real-world datasets.

## Objectives

- Analyze global COVID-19 trends across countries and regions
- Identify peak infection surges and mortality patterns
- Compare recovery and death rates between countries
- Perform time-series analysis using cumulative datasets
- Apply Python libraries for real-world data analysis and visualization

## Dataset Description

   ### The project uses three COVID-19 datasets:
   
    -Confirmed Cases Dataset
    -Contains cumulative confirmed COVID-19 cases per day
    
   ### Deaths Dataset
   
    -Contains cumulative deaths attributed to COVID-19
    
  ### Recovered Dataset
  
   Contains cumulative recoveries from COVID-19
   Date Range: **22 January 2020 – 29 May 2021**
   Geographic Coverage: **276+** countries and regions
   
  ### Each dataset includes:
  
  - Province/State
  - Country/Region
  - Latitude & Longitude
  - Daily cumulative values (wide format)
